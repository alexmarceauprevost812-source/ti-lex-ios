# Intégration TI-LEX

Le bureau XFCE et l'installateur Calamares de la branche principale sont conservés. Les images locales, l'aperçu orange et les outils Geany/Git Cola/Meld sont intégrés. Java utilise default-jdk de Debian 13.

Les animations web, la météo et le code de partage téléphone ne constituent pas des services Linux opérationnels. Le pilote nvidia-driver précédemment proposé ne garantit pas le support RTX 5060 : validation spécifique encore nécessaire. L'ISO doit être testée en VM avant installation physique.
