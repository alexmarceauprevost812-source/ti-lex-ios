# Aperçu Vercel

Aperçu interactif HTML/CSS/JavaScript : bureau, paramètres, terminal simulé,
clic droit sur un ZIP de démonstration, lanceur et écran de connexion.
Il reprend les visuels de l'image Linux, dont la planche file-tools.png pour les formats
de fichiers et les outils système. La disposition web est une présentation,
pas une capture ni une émulation du bureau XFCE réel.

Depuis la racine : `node preview/build.mjs`.
Vercel détecte vercel.json et publie uniquement public/.
Aucun secret, API serveur, exécution de commande ou accès aux fichiers visiteurs.
Le contenu des archives présenté ici est fictif.
L'ISO n'est ni construite ni hébergée par cet aperçu.
