# Travail local TI-LEX Pro

Le dossier codex-local contient les 89 fichiers sources et visuels locaux du 13 septembre 2026. Les sorties public/ reproductibles et caches Python sont exclus.

Cette copie est conservée séparément parce que la branche Claude possède des corrections plus récentes de l'installateur, des tests et du démarrage. Elle n'est pas encore fusionnée dans la configuration ISO active à la racine.

L'aperçu web se construit depuis codex-local avec node preview/build.mjs. La météo et le partage téléphone sont des maquettes, sans service de transfert ni météo réelle. Les animations web ne configurent pas les fenêtres XFCE. Le fond desktop-lexos.png contient encore un nom de marque à corriger. L'installation et le support matériel restent à valider en VM.
