# Page d’installation TI‑LEX Pro

Depuis le mode live, ouvrez **Installer TI‑LEX Pro**. L’assistant Calamares propose une installation graphique avec langue française canadienne, clavier canadien, fuseau `America/Toronto`, choix du disque, création du compte utilisateur et résumé de confirmation.

Le mode live permet de tester le matériel avant de lancer l’installation. L’assistant demande une confirmation avant d’écrire sur le disque.
