# Essayer TI-LEX avant installation

L’ISO démarre en mode live grâce à `live-boot` et `live-config` : choisissez **Essayer TI-LEX Pro** dans le menu de démarrage. Le bureau, le réseau, les outils développeur, le support NVIDIA/Mesa et les réglages peuvent être testés depuis une clé USB ou une machine virtuelle sans modifier le disque.

L’installation sur disque doit être lancée séparément depuis l’installateur Debian lorsque le test est terminé. Les fichiers créés pendant la session live sont temporaires sauf si une persistance est configurée.
